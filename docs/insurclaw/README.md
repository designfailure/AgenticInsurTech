# InsurClaw Architecture Pack

This folder provides a full architecture + orchestration specification for **InsurClaw**, an autonomous agentic InsurTech system inspired by OpenClaw patterns and adapted as a **clone-mimic alternative**.

## Document map

1. `01-product-spec.md`  
   Product vision, operating principles, domain boundaries, and key scenarios.
2. `02-architecture-orchestration.md`  
   Multi-agent architecture, runtime orchestration, state transitions, and failure handling with Mermaid diagrams.
3. `03-component-functional-spec.md`  
   Functional specifications for every core component and agent domain.
4. `04-openclaw-clone-mimic-blueprint.md`  
   OpenClaw-to-InsurClaw mapping with compatibility notes and implementation guidance.

## Scope covered

- Financial literacy
- Prevention as a Service
  - Event
  - Extreme Weather
- Underwriting
  - Risk engine
- Claim assessment
  - Loss adjuster
  - Appraisal
  - Assessor
  - Evaluation (estimation)
